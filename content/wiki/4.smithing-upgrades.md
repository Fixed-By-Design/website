# Smithing Upgrades

Four templates replace twelve vanilla enchantments. You apply them at a smithing table.

## The recipe

Smithing table, three inputs:

1. **The template.** Honing, Warding, Tempering or Grinding.
2. **The item.** It must be eligible for that template.
3. **The ingot.** This decides the level.

| Ingot | Level |
| :-- | :-- |
| Copper | I |
| Iron | II |
| Gold | III |
| Diamond | IV |
| Netherite | V |

No experience is charged. Ever.

::note
The table produces nothing unless the result would be strictly higher than what the item already has. You cannot accidentally downgrade a Netherite-honed sword by putting copper in.
::

## What each one does

**Honing** applies to weapons, bows and crossbows. Replaces Sharpness and Power.

| Level | Attack damage |
| :-- | :-- |
| I | +1.0 |
| II | +1.5 |
| III | +2.0 |
| IV | +2.5 |
| V | +3.0 |

A honed bow or crossbow adds the same bonus to arrow damage.

**Warding** applies to armor. Replaces the entire Protection family.

3.2% damage reduction per level per worn piece, summed across four pieces, capped at twenty total levels. Full Warding V on all four pieces is 64% against everything.

**Tempering** applies to anything damageable. Replaces Unbreaking.

| Level | Equivalent |
| :-- | :-- |
| I, II | Unbreaking 1 |
| III, IV | Unbreaking 2 |
| V | Unbreaking 3 |

**Grinding** applies to mining tools. Replaces Efficiency.

| Level | Mining speed |
| :-- | :-- |
| I | +2 |
| II | +5 |
| III | +10 |
| IV | +17 |
| V | +26 |

## Duplicating a template

Seven copper ingots, one template, one material, in the standard template duplication pattern. Yields two.

| Template | Material |
| :-- | :-- |
| Honing | Flint |
| Warding | Iron Ingot |
| Tempering | Obsidian |
| Grinding | Stone |

## Finding templates

| Template | Where |
| :-- | :-- |
| Honing | Village Weaponsmith 20%, Pillager Outpost 25%, Stronghold Library 30%, Simple Dungeon 20% |
| Warding | Village Armorer 20%, Bastion Treasure 30%, Buried Treasure 25%, Jungle Temple 25% |
| Tempering | Village Toolsmith 11%, Desert Pyramid 25%, Shipwreck Treasure 20%, Abandoned Mineshaft 12% |
| Grinding | Abandoned Mineshaft 12%, Ruined Portal 25%, Trial Chamber rare reward 17.6% |

::tip
Because duplication costs copper rather than diamonds, the first template of each type is the hard part. After that, scaling up is cheap. Prioritise finding one of each over stockpiling any single one.
::

## Advancements

| Advancement | How |
| :-- | :-- |
| Hammer Time | Take your first smithing upgrade out of the table |
| Jack of All Trades | Apply Honing, Warding, Tempering and Grinding at least once each |
| Walking Fortress | Wear all four armor pieces at Warding V |
