# Installation

Fixed by Design ships as **Fixed SMP**, a Modrinth modpack. You do not install the mods individually unless you are building your own pack.

::warning
The pack is not published yet. This page describes how installation will work once it is. Follow the [roadmap](/roadmap) or [send feedback](/feedback) to hear when it lands.
::

## Requirements

| | |
| :-- | :-- |
| Minecraft | 26.1.2 |
| Mod loader | Fabric Loader 0.19.2 or newer |
| Java | 25 or newer |
| Memory | 6 GB allocated is comfortable, 4 GB is the floor |

## Installing with a launcher

Any launcher that reads `.mrpack` files works. The Modrinth App, Prism Launcher and ATLauncher all do.

1. Open the pack on Modrinth.
2. Pick the **full** variant unless you know you want client-only or server-only.
3. Install, then launch once before joining anything, so resource packs finish unpacking.

::note
Three variants are published for every release: **server**, **client** and **full**. The full pack is what the project page offers by default and is the one you want for singleplayer or for joining a server.
::

## Installing on a server

Use the **server** variant. It excludes client-only mods and the resource packs, which keeps the jar count and memory footprint down.

Fairlands, the server rules mod, is where the gamerules described throughout this wiki live. Most of them can be changed with `/gamerule`, and the rest are in the in-game config screen.

## Shaders

The pack ships Complementary Reimagined and Complementary Unbound, with Unbound preselected but **shaders turned off**. A fresh install is not GPU-bound. Turn them on in Video Settings when you want them.

## Updating

Update through your launcher. Worlds carry forward between versions of the same Minecraft release.

::warning
Read the [changelog](/changelog) before updating a world you care about. Breaking changes are listed there explicitly, and some redesigns cannot be reversed by downgrading.
::

## When a world will not load

Almost always a version mismatch: the world was saved with a newer pack than the one you are opening it with. Check the pack version in your launcher against the version the world was last opened with.

If that is not it, [send us the log](/feedback?type=bug). Include the pack version and whether it is singleplayer or a server.
