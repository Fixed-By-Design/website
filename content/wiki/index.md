# The Fixed by Design wiki

Fixed by Design is an opinionated Fabric modpack that redesigns Minecraft Survival. It is not a kitchen-sink pack and it does not add a tech tree. The world you load looks like Minecraft and plays like Minecraft, and then behaves differently in specific, deliberate places.

This wiki documents those places.

## What the project is trying to do

Minecraft Survival has excellent foundations. Over fifteen years, several of its systems accumulated problems that have nothing to do with the ideas underneath them: dominant strategies that crowd out every alternative, progressions that one item trivialises, rules written for one player and then applied to twenty, whole mechanics nobody has a reason to touch, and features that quietly delete other features.

Every change here starts from the same four questions.

1. What was this system trying to achieve?
2. What behaviour does it actually reward?
3. Where does it become tedious, dominant, irrelevant or broken?
4. Can it be improved without making Minecraft feel like a different game?

The answer is never "add more". It is usually "give this system back its decision".

::note
Fixed by Design is opinionated by construction. Where a change is contentious, the reasoning is published rather than hidden, and most server-side rules have a gamerule that turns them off.
::

## What lives where

This wiki answers **how do I use this mechanic**. It is the reference you open while playing.

[Features](/features) answers **what changed and why**. Each feature page states the vanilla behaviour, the design problem, and the fix.

[Design decisions](/design) answers **why we chose this over the alternatives**. Problem, evidence, constraints, considered solutions, decision, consequences.

[Roadmap](/roadmap) is what is coming next. [Changelog](/changelog) is what already shipped.

## The four mods

The pack is built on four first-party mods. You do not need to know their names to play, and nothing in this wiki is organised by them, but they are what the Features section maps back to.

| Mod | What it rebuilds |
| :-- | :-- |
| Enchantment Overhaul | Enchanting, smithing, repairs, armor materials |
| Exploration Reloaded | Elytra flight, maps, fishing, mounts, world spacing |
| Fairlands | Death, bonus hearts, spawn rules, PvP, ore progression |
| Minecarts Overhaul | Rails, locomotives, trains |

Everything else in the pack is third-party. [Bundled Mods](/wiki/bundled-mods) covers the ones that change how the game plays, and [the modpack](/modpack) has the full list.

## If something feels wrong

Tell us. [Send feedback](/feedback) from here, or run `/feedback <message>` in game on a server running Fairlands. Playtesting is how this project makes decisions, and every message is read.
