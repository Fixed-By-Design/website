# Installation

Fixed by Design est distribué comme **modpack Modrinth**. Vous n’avez pas à installer les mods un par un, sauf si vous composez votre propre pack.

::warning
Le pack n’est pas encore publié. Cette page décrit l’installation prévue. Consultez la [feuille de route](/roadmap) ou [donnez votre avis](/feedback) en attendant sa sortie.
::

## Prérequis

| | |
| :-- | :-- |
| Minecraft | 26.1.2 |
| Chargeur de mods | Fabric Loader 0.19.2 ou plus récent |
| Java | 25 ou plus récent |
| Mémoire | 6 Go alloués conseillés, 4 Go au minimum |

## Installer avec un lanceur

Tout lanceur compatible avec les fichiers `.mrpack` convient, notamment Modrinth App, Prism Launcher et ATLauncher.

1. Ouvrez le pack sur Modrinth.
2. Choisissez la variante **full**, sauf si vous avez besoin de la version client seule ou serveur seule.
3. Installez le pack et lancez-le une première fois avant de rejoindre une partie, pour laisser les packs de ressources se décompresser.

::note
Chaque version est prévue en trois variantes : **server**, **client** et **full**. La variante full est celle proposée par défaut, pour jouer en solo ou rejoindre un serveur.
::

## Installer sur un serveur

Utilisez la variante **server**. Elle exclut les mods réservés au client et les packs de ressources, ce qui réduit le nombre de fichiers JAR et l’utilisation de mémoire.

Fairlands contient les règles serveur décrites dans ce wiki. La plupart se modifient avec `/gamerule`, les autres dans l’écran de configuration en jeu.

## Shaders

Le pack inclut Complementary Reimagined et Complementary Unbound. Unbound est présélectionné, mais **les shaders sont désactivés**. Une installation neuve n’impose donc pas leur charge à la carte graphique. Activez-les dans les options vidéo quand vous le souhaitez.

## Mettre à jour

Passez par votre lanceur. Les mondes peuvent suivre les mises à jour du pack pour une même version de Minecraft.

::warning
Lisez les [notes de version](/changelog) avant de mettre à jour un monde auquel vous tenez. Les incompatibilités y sont indiquées. Revenir à une ancienne version ne permet pas toujours d’annuler une refonte.
::

## Si un monde ne se charge pas

Il s’agit le plus souvent d’un décalage de version : le monde a été sauvegardé avec un pack plus récent. Comparez la version du lanceur à celle utilisée lors de la dernière ouverture.

Sinon, [envoyez-nous le journal](/feedback?type=bug), avec la version du pack et en précisant s’il s’agit d’une partie solo ou d’un serveur.
